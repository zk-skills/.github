# zk-skills

独立 AI Skill 仓库集合。每个仓库只维护一个 Skill，便于单独安装、引用、版本管理和持续迭代。

| Skill 仓库 | 说明 |
|---|---|
| [elegant-ancient-narrative-style](https://github.com/zk-skills/elegant-ancient-narrative-style) | 古雅叙事风格引擎：将现代文本转化为具有古雅气韵的现代表达，通过叙事视角、情绪节制、语言节奏和思想层次完成转换。 |
| [human-ui](https://github.com/zk-skills/human-ui) | 去 AI 味的高级前端 UI 设计引擎：提供经典设计语言、动效配方与 AI 味反模式自查清单。 |
| [image-gen](https://github.com/zk-skills/image-gen) | 通用 AI 图像生成 Skill：兼容 OpenAI / NewAPI 协议，支持同步、异步、批量并行与自定义服务商。 |
| [manga-studio](https://github.com/zk-skills/manga-studio) | AI 漫画工作流：从剧情、角色和世界观素材产出设定、角色参考表、分镜脚本、布局草图与成稿画面。 |
| [premium-cover-design](https://github.com/zk-skills/premium-cover-design) | 高级出版物封面设计引擎：26 套设计配方、18 套混合风格、16 套布局、32 组字体组合、5 套署名原型与质量门禁。 |
| [super-creazy-html-ppt-in-work](https://github.com/zk-skills/super-creazy-html-ppt-in-work) | 高端 HTML 幻灯片生成器：多主题、多布局、SVG 图标系统、动画与 16:9 演示优化。 |
| [deck-image-prompting](https://github.com/zk-skills/deck-image-prompting) | 图片型 PPT 的整套逐页生图提示词系统：视觉 DNA、背景锚点、结构母版、字体层级和页面类型。 |
| [marketing-deep-research](https://github.com/zk-skills/marketing-deep-research) | 严格复刻 Aippt 营销 Agent 可观察 Deep Research 行为的证据约束型 Skill。 |

## 安装

进入对应仓库，将其复制到项目的 `.agents/skills/` 或用户的 `~/.codex/skills/` 目录。每个仓库的 `SKILL.md` 是 Agent 执行入口。
